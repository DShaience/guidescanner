The Gst-nvdspostprocess plugin is released in DeepStream 6.1. The plugin supports parsing of various inferencing models
in DeepStream SDK. The plugin can perform parsing on the tensors of the output layers provided by the Gst-nvinfer and Gst-nvinferserver.
The aim of this document is to provide guidance on how to use the Gst-nvdspostprocess plugin for various inference models.

Description
